# Todo App (React)

A modern and interactive Todo application built using React, focused on
productivity and smooth user experience.

## ✨ Features
- Add new tasks
- Delete existing tasks
- Mark tasks as completed
- Drag and drop tasks to reorder
- Clean and responsive UI
- Real-time task updates

## 🛠 Tech Stack
- React
- JavaScript (ES6+)
- CSS

## 🚀 Live Demo
👉 https://yasin7428.github.io/TODO-APP/

## 📌 What I Learned
- Managing state in React
- Handling user interactions efficiently
- Implementing drag and drop functionality
- Writing clean and reusable components

## 📂 Project Setup
1. Clone the repository
2. Install dependencies  
   `npm install`
3. Start the development server  
   `npm start`
